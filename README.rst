=====================
Web Responsive Custom
=====================

This module provides custom refinements for the ``web_responsive`` module.

Key Improvements:
-----------------
* **Persistent Apps Menu State**: The Apps Menu now synchronizes with the URL hash (``#home``). 
  Refreshing the page while the menu is open will keep it open.
* **Refined UI**: The main toolbar color has been changed from the default Odoo blue 
  to a more professional dark slate grey (#2c3e50).
* **Improved Hover States**: Navigation entries now have a subtle hover effect for better feedback.

Installation:
-------------
Simply install this module. It depends on ``web_responsive``.
